# Portfolio · Slimane Benmayouf

Portfolio Next.js avec App Router, TypeScript et CSS responsive. Interface français/anglais, préférence de langue mémorisée, filtres de projets et fiches détaillées. Le contenu provient du CV fourni ; les aperçus graphiques sont des illustrations conceptuelles, pas des captures des produits.

## Démarrer

```sh
npm install
npm run dev
```

Ouvrir http://localhost:3000.

## Production

```sh
npm run build
npm start
```

Les textes et projets se trouvent dans `app/page.tsx`, les styles dans `app/globals.css`. Le CV original est proposé au téléchargement au format texte. Les polices Google Fonts disposent de polices de repli système. Aucun formulaire ni service externe n’est requis : les liens de contact utilisent email et téléphone.
